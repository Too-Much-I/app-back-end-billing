# PLAN-011 J4 — MEMBER 증거 보존·기존 탈퇴 연동 채택

- 날짜: 2026-10-14
- 상태: 사용자 제품/설계 방향 승인. exact 전달 계약·schema·구현·공동 검증·배포는 미완료.
- 승인 근거: MEMBER→GUEST 전환 없음, 탈퇴 외 상태 없음, 일부 전달 지연 허용이라는 사용자 설명 및 「j4도 1번으로 해줘」.
- 관련: PLAN-011/012/013, TMI-116/TMI-128/TMI-122, TMI-125.

## 1. 5줄 결론

1. Identity가 확인한 MEMBER 증거를 Billing에 보존하는 ①을 채택한다.
2. MEMBER→GUEST 전환이 없으므로 시험마다 회원 유형을 동기 조회하지 않는다.
3. 탈퇴는 기존 Identity 이벤트·누락 복구 경로로 반영하며 일정 전파 지연을 허용한다.
4. Billing에 탈퇴가 반영된 이후 신규 reserve/confirm은 차단하며 보존된 MEMBER 증거가 deny를 덮어쓰지 못한다.
5. 증거 최초 전달·기존 사용자 보강·지연 운영 기준은 기술 계약으로 구체화하고 원문 사용자 JWT를 저장/재사용하지 않는다.

## 2. 사용자가 반드시 읽어야 하는 내용

MEMBER는 계정 유형 증거이고 탈퇴 여부는 별도 lifecycle 사실이다. 보존된 MEMBER 증거 + Billing이 관측한 현재 탈퇴 deny로 판정한다. Billing 로컬 ACTIVE를 실시간 Identity ACTIVE라고 주장하지 않는다. 탈퇴 이벤트가 도착하기 전 승인될 수 있는 지연은 사용자 수용 범위다. 무제한 지연/복구 중단을 허용하는 결정은 아니다.

worker도 사용자 JWT 없이 보존 증거와 lifecycle를 읽는다. 탈퇴 선행 여부는 Billing 적용 Transaction과 T2의 공통 fence 쓰기 순서로 판정한다. Identity 원격 commit과 Billing commit을 하나의 분산 Transaction으로 취급하지 않는다. 이미 성공한 confirm의 금융 사실은 보존하되 LC의 탈퇴/삭제 deny를 우회해 시험을 재생성하지 않는다.

## 3. 남은 기술 확인

| 항목 | 방향/미확정 |
| --- | --- |
| 최초 MEMBER 증거 | Identity 권위가 검증되는 기존 경로를 우선 재사용. exact 발급/수신 경로·field·사용자/환경/목적 결속은 확인 후 확정 |
| 저장 | 최소 owner 식별·증거 출처/종류·최초 검증 시각·필요 epoch를 정규화. 사용자 토큰 원문 저장 금지 |
| 기존 계정 | 이미 있는 payment account/구매 사실만으로 MEMBER 증거를 임의 backfill하지 않음. 확인 가능한 원 증거 또는 승인된 보강 절차 필요 |
| 부재/장애 | 증거 없음을 GUEST로 분류하거나 trial로 우회하지 않음. 확인/복구 대상으로 처리, exact 오류·재개 조건은 공동 확정 |
| 지연 | 기존 withdrawal push/feed·복구 사용. 관측 지연 경보·복구 기준 및 장애 시 정책은 기존 계약과 대조. 임의 초/분 수치 추가 없음 |
| 보존/폐기 | 사용자 귀속·탈퇴 deny·중복 차단 증거의 보존은 V07과 연계. MEMBER 유형이 안정적이라는 이유로 개인정보를 영구 보존하지 않음 |

회원 상태 전체를 새 이벤트 시스템으로 실시간 동기화하거나 시험마다 Identity를 동기 호출하는 방식은 기본안에서 제외한다. 최초 증거 보강에 필요한 호출/전달을 금지한다는 뜻은 아니다. paid/MEMBER 보상권 정상 경로의 활성화는 이 최소 증거 연결과 검증이 준비된 후다.

## 4. 주요 위험과 미확인 사항

탈퇴 전달 지연 중 사용 가능성이 남는다. 기존 누락 복구와 관측을 유지하고, 탈퇴 반영 후에는 뒤늦게 도착한 MEMBER 증거가 계정을 다시 ACTIVE로 만들지 못하게 한다. 재가입의 다른 userId로 기존 권리를 자동 이전하지 않는다. source별 owner/일반 version/ownership epoch 규칙은 J4 보완안을 유지한다.

## 5. 구현·공동 문서 반영 범위

[J3/J4 draft-2](LC-BILLING-PAID-EXAM-J3-J4-ADDENDUM-R1.md)의 「방식 미선택」은 이 승인 범위에서 대체한다. 최초 증거 전달 exact와 source별 적용 테스트가 미완료라는 경계는 유지한다. LC/Identity 최종 공동 수락으로 확대하지 않는다. R2/fixtures-2 원본 bytes는 변경하지 않는다.

## 6. 부록 — 후속 검증

MEMBER 증거 최초 저장/중복, 증거 없음 복구, worker의 토큰 없는 사용, 탈퇴와 confirm 양순서, 늦은 MEMBER 증거의 탈퇴 부활 금지, source별 owner 보존을 테스트 명세에 반영한다. 실제 fixture 제작/제품 테스트는 아직 실행하지 않았다. 이번 작업은 정책 문서·참조·작업 기록 갱신뿐이다.
